A one-image summary of the world news of Thursday 19 November 2026, drawn as a newspaper front page: the first-ever Trump–Xi–Putin three-way summit in Shenzhen and its joint peace declaration, the ICJ ruling that Myanmar committed genocide against the Rohingya, Israel's first ground raid into central Gaza since the ceasefire, tanker attacks in the Strait of Hormuz, Ukraine's strike on the Kerch Bridge, Anthropic's record $81B IPO, Voyager 1 reaching one light-day from Earth, and the Senegal migrant-boat disaster — plus a ticker of the day's other stories. The program writes this image to `/output/entry.png`.

## Run it

```sh
python3 main.py
```

That copies the shipped `entry.png` to `/output/entry.png` (set `MAKEFUN_OUTPUT_DIR` to write somewhere else). Python 3 standard library only; no network needed, and every run writes identical bytes.
